ABOUT THE LIBRARY

开放知识，清晰边界。

一个专注阅读与学习的机器人论文库。提供按协议分组的作者报告结果，不是官方全量榜或自动复现平台。

01 / EVIDENCE

记录结论，也记录条件

每篇记录包含贡献、作者报告的量化结果、限制和原始来源。百分比、百分点、动作头加速和整机加速不混用。

文献库在首批 46 篇近期工作之上补入了 32 篇奠基性、代表性论文与数据 / 评测资源，覆盖 2021—2026 年；“关键文献”是编辑精选，不是引用量排名，也非穷尽列表。标为“笔记待复核”的记录保留先前整理内容，网站迁移时没有重新逐项核对全文。

“已复核片段”仅表示核对了所列原文片段，不意味着整篇核验或独立复现。期刊投稿与正式录用也会分开标注。

02 / PRIVACY

公开事实，私有进度

公开数据只包括论文及面向所有读者的阅读提示，不包含任何私人研究方案。网站不设置账号、不使用分析埋点，检索在浏览器内计算，收藏和阅读状态不提交服务器。

收藏和阅读进度使用本浏览器的 localStorage，不是加密保险箱，也不会自动跨设备同步。请不要在共享设备上保存敏感信息。

访问托管网站仍会产生 GitHub Pages 的常规访问日志。分享筛选链接会把检索词和筛选条件放入 URL，请勿分享敏感检索。点击外部论文链接后适用对方网站的隐私规则。

03 / READING

阅读建议，不是质量评级

精读：适合深入阅读方法、消融与证据链。
选读：提炼局部方法或某类结果。
了解：建立背景、技术前提或应用边界。

建议仅从公开的方法价值与证据可解释性出发。你可以把任意论文加入自己的本地清单，并随时调整阅读状态。

04 / MAINTENANCE

一份数据，持续积累

文献源为 catalog/papers/ 下逐篇记录。构建器生成检索目录、按需详情与兼容 JSON 导出；周更在独立分支核验并创建 PR，来源自检和 CI 通过后按授权合并发布。

新增论文应先核对原始来源，再填写结论和边界。可运行 python scripts/validate/validate_schema.py 检查数据结构、node tests/node/test_dates.cjs 检查周历；它们不会自动验证论文事实。周次由首发日期自动计算，不增加待人工同步的日期字段。
