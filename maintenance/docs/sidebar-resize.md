# 可拖拽导航宽度（2026-09-18）

在导航栏右边缘拖拽以调整宽度；双击或按Enter恢复默认。键盘左右键每次8px，Shift为24px，Home/End到最小/最大，Esc取消本次拖动。桌面默认260px、范围244–380px，窄窗自动限制并为主内容区保留至少400px；700px及以下继续使用手机抽屉，隐藏拖拽手柄，不覆盖桌面偏好。导航标题和徽标保持单行。

宽度只保存在本浏览器的vla-radar.sidebar-width.v1，不上报、不加入阅读备份，不改动reading.v1。禁用存储时仍能调宽；异常值回退默认，窗口缩放只钳制显示，不抹掉较宽屏幕的原偏好。拖拽用requestAnimationFrame合并样式更新，仅结束时写存储；无第三方依赖、无数据请求，失焦/指针取消/捕获丢失结束临时拖动状态。打印隐藏手柄。

sidebar.js与sidebar.css为轻量布局资产，不触发论文、结果或新闻预加载。新增scripts/browser/browser_sidebar.py真实HTTP浏览器回归，并纳入site.yml的PR及发布CI。测试包含鼠标、键盘、复位、刷新恢复、窄屏、移动抽屉、存储拒绝、取消捕获与既有阅读状态不变性。CI视口模拟不等于真实手机测试。
