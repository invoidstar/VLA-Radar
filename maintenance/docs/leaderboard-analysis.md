# Leaderboard列排序与时间—成绩图（2026-09-19）

本次是维护者明确要求的现有榜单改进，不恢复大规模功能扩张。

## 排序

所有协议内的成绩列均可通过「排序 / 图表指标」或表头按钮选择；再次点击同一表头切换升降序。排列方式有自动较优值优先、数值升序、数值降序及恢复原记录顺序。自动方向来自协议的direction，不能从指标名称猜测；NBT等lower指标默认升序。

全体有效记录先排序，再分页，每页20条。缺失值/非有限数字始终置后（恢复原记录顺序时不重排）；真实零值、负值、并列均保留。protocol的名次按该指标的优劣方向独立计算，反转显示顺序不会使最差分数获得第一名；paper-table允许排列但不显示公平名次。候选和被替代记录不进入现行图表。原始JSON和canonical顺序不被浏览器排序改写。

## 时间—成绩散点图

仅使用当前选定协议和成绩列；与原条形图切换，并与表格保持同一指标。首次打开图表才加载工作台代码，使用已加载的轻量论文目录和当前赛道分片，不加载全库正文或历史榜单，也不引入第三方绘图库。

横轴可选择：

- 来源论文首次公开日期：取结果reporting paperId所对应论文的firstPublished。对于同文引用基线，这不是该基线方法的首次发布时间；也不是该成绩的实际实验日期。同一来源论文的基线可共用日期，提示必须保持可见。
- 本站结果核验日期：取结果verifiedAt，不冒充模型发布日期、实验执行日或论文首发。

两种口径均只绘制精确YYYY-MM-DD且真实存在的UTC日期。未知/仅年/仅月日期不猜补，不回退今天、出版日或另一口径。原记录仍在表格与CSV，散点CSV逐条给出可绘制状态和缺失原因。第一种日期不是当前sourceVersion的自动发布日期；不以此图宣称全领域技术进步趋势。

成绩保持原单位，不将平均链长、终身学习指标或部分覆盖率写成完整成功率。不连线、不拟合趋势、不补造误差。完全重合的日期—成绩坐标显示记录数量，悬停、点选、键盘聚焦可逐条展开模型、报告论文、预算和源表。不平均、不抖动坐标或改动日期来避免重叠。仅单日数据要明确提示不是时间趋势；空数据显示原因。

每张图最多500个不同坐标，按日期再数值排列，明确显示截取数量；图例详情每次10条。表格和CSV仍包含全部当前协议的有效记录，CSV包括缺失日期/成绩行。不同协议绝不因为同数据集名而混图。

## 链接、可访问性与回归

`lbMetric`、`lbOrder`、`lbChart`、`lbTime`保存公开的展示选择，可刷新和分享；不写私人阅读存储。表头为原生按钮，只有当前排序列带aria-sort，键盘操作后保持焦点。散点可Tab/Enter/空格操作，原表与CSV作为替代阅读路径；小屏宽图在自己的区域滚动。

本地离线校验新增tests/node/test_leaderboard_controls.cjs；正式CI新增scripts/browser/browser_leaderboard.py，包含真实HTTP交互、方向、缺失、同坐标展开、未知日期、CSV、刷新、小屏及旧存储/按需加载验证。CI浏览器/视口不代表真实手机或移动网络。以后每周内容构建自动进入这些功能，不降低科学来源标准，不为画图补造方法日期。


## 来源分组导航（2026-09-19）

默认先选数据集，再选来源论文／官方榜单，最后选同一来源的具体评测设置。来源组基于已记录来源的规范标识（arXiv ID、DOI、PMLR论文路径、论文集hash或保留查询条件的URL），缺少来源时独立成组。不从题目相似度猜论文身份，组名仅导航文本。同源不同版本可在一组中切换，但每个track仍独立；RoboCasa与RoboCasa365从数据集层隔开。

“查看全部设置”保留原平铺入口；深链接的track自动定位其来源组，lbMetric/lbOrder/lbChart/lbTime均保持，lbBrowse=all记录平铺视图。当前组与原始设置不落入私人阅读存储。完整协议默认折叠但保留版本、指标、划分摘要，展开可查看全部训练预算与来源。

分组绝不合并不同指标、预算、视角、checkpoint或真机/仿真结果；排序、CSV与散点图始终针对一个精确track。无需手工给每条新结果维护一份分组表；只使用已加载目录，不因导航预取其他track或全库正文。新增来源可自然形成新组；来源为null或格式无效时不可自动归并。
