# 阅读工作台（2026-09-18）

## 页面入口

- `?view=reader&paper=p001`：独立专注阅读页。字号、行距和纸色／浅色／夜读设置，以及每篇阅读位置仅保存在浏览器；原有收藏和阅读状态键不变。笔记版本变化时不自动跳到旧位置。保留逐节来源、原图定位、解释表、来源限制与发表历程。
- `?view=compare&compare=p001,p069`：2–4篇对比。维度来自现有笔记中匹配的章节摘录，可展开全文和来源。缺失项不补猜；“摘录不同”不是性能显著差异。比较选择可分享，但收藏／私人进度不进入链接或导出。
- `?view=updates`：按新收录、修订、发表、笔记、结果、网站更新筛选。历史笔记和评测快照不构造首次入库日期；仅明确观测到的事件参与上次访问比较，只有日期的事件保守处理。
- `?view=coverage`：研究方向×数据集的来源覆盖热力图。只统计checked、未被supersedes替代的结果，论文数按报告该结果的paperId去重。方向可交叉；零格不表示领域无研究，deferred不猜测映射。格子下钻最多展示30篇，避免无界DOM。
- 评测榜单内“查看当前协议图表”：当前赛道和单个指标的横向条形图；paper-table保持原表顺序、不赋名次。真实零值保留，null不画零分；百分比轴至少0–100，不补造误差条。最多40行图示，完整记录保留表格与CSV。
- 单篇／当前筛选／对比清单导出：基本BibTeX（标题、首发年、arXiv、已知DOI、实际阅读版本）和完整Markdown。团队字符串不冒充作者名单，最终作者/刊会书目信息请核对原文。CSV防公式注入。BibTeX单次最多200篇，完整笔记最多100篇，并发最多4项；失败不静默输出缺篇结果。空对比清单不退化为全库导出。

## 构建、周更与真实变更

`build_catalog.py`调用`experience_build.py`，确定性生成`data/experience/`下的内容哈希分片。首页仅多一个入口路径，不下载整张热力图、全部更新、全文笔记或图表。模块在实际使用时才载入；事件流按类型每片最多50条。

每次周更在确认最新main的精确SHA后保留为`BASE_SHA`。完成实际canonical内容修改后运行：

```bash
python scripts/capture_activity.py --base "$BASE_SHA"
python scripts/build_catalog.py
python scripts/validate_all.py
python scripts/browser_workspace.py
```

capture_activity只把与BASE_SHA对照的真实新增、笔记正文／阅读版本、发表元数据和结果差异追加到catalog/activity.json；事件ID按内容生成，同一变化重跑不重复。lastCheckedAt或needs_review单独变化不冒充新精读。日期时间为本站观察时间，不替代论文首发日期。旧记录快照仍保持snapshot标识，不回填不存在的历史变化。维护该日志及构建生成文件与同一内容PR一起提交，不在CI校验环节临时改数据，也不推进发现检查点。

来源、科研结论、笔记和原有结果本轮均不改写。新论文仍必须满足8节、正文范围与逐篇榜单处理要求。分支清理、发表同步、主分支保护边界及正常PR自检发布流程不变。

## 验证与可访问性

validate_all包含纯函数与构建测试：链接/HTML/BibTeX/CSV安全、快照与真实事件区分、活动幂等、论文来源去重、协议内零/缺失值、分片上限和新增资源预算。browser_workspace在真实HTTP下验证路由、阅读位置与偏好、旧进度键、对比、筛选、热力图、图表和文件导出；本地离线注入预览不能代替发布CI。保留键盘焦点、原生dialog的Escape、可滚动表格标题与来源；尊重减少动画偏好。隐私状态不提交服务器。CI手机尺寸不等于真实手机硬件或移动网络实测。
